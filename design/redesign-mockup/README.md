# Fieldbook redesign mock-up

A draft of how the app could look and work. Nothing here is wired into the app yet.

- `pack/Fieldbook-redesign.html` is the clickable mock-up. Open it in a browser. It works offline.
- `pack/screens/` has 34 screenshots: Mac light, Mac dark and phone.
- `pack/READ-ME-FIRST.md` explains each screen and lists the gaps we already know about.
- `fieldbook-redesign.src.html` is the source page. The scripts in `build/` fill it with real manual passages and take the screenshots. Paths in those scripts are placeholders (`SCRATCH`, `REPO`), so set them before running.
- `audits/search-audit-results.md` shows how today's search did on 28 test searches.

All household data in the mock-up is example data. The example map point is in downtown Austin.
